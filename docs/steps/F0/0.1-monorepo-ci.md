## Track I · Tooling

Rama `step/0.1-infra`.

**Entregables**

1. **Árbol de primer nivel** exacto de `repo-structure.md §1`, con `README.md` de una línea en cada carpeta vacía.
2. **Raíz:** `.editorconfig` (UTF-8, LF, 4 espacios C#/Kotlin, 2 espacios TS/JSON/YAML/SQL), `.gitattributes` (`* text=auto eol=lf`), `.gitignore` (.NET, Node, Gradle, IDEs, `.env`), `.env.example` vacío con cabecera.
3. **`Makefile`** con estos targets. Los que dependen de pasos posteriores imprimen `"pendiente: paso X.Y"` y salen con código 0:
   `up`, `down`, `reset`, `doctor`, `db-migrate`, `seed-dev`, `contracts`, `mock-api`, `build`, `test`, `test-rls`, `test-e2e`, `lint`, `rule-coverage`.
4. **.NET** (`src/`):
   - `Nexus.sln`, `Directory.Build.props` (`net10.0`, `Nullable=enable`, `TreatWarningsAsErrors=true`, `ImplicitUsings=enable`, analizadores .NET en nivel `recommended`), `Directory.Packages.props` con **todas** las versiones de `conventions-backend.md §10` (última estable al ejecutar el paso).
   - Proyectos vacíos de `BuildingBlocks/*` (los siete de `repo-structure.md §2`) y `Contracts/Nexus.Contracts.Events`.
   - `BuildingBlocks/Nexus.BuildingBlocks.Testing` + un proyecto `tests/Nexus.Architecture.Tests` con un test que verifica que ningún ensamblado `Nexus.*.Domain` referencia EF Core, ASP.NET Core ni Confluent.Kafka (`conventions-backend.md §2`).
5. **Angular** (`web/`): workspace generado con el CLI estable (`--standalone --routing --style=scss --ssr=false`), ESLint (`@angular-eslint`) y Prettier. Sin pantallas: eso es 0.5.
6. **Contratos** (`contracts/`):
   - `openapi/.spectral.yaml`: reglas de Spectral `oas` + reglas propias: `operationId` camelCase; toda operación tiene `x-permission` con formato `^[A-Z_]+:[A-Z_]+$|^PUBLIC$`; toda operación `GET` de lista tiene `page`/`pageSize` o `limit`/`cursor`; toda respuesta 2xx tiene `example` (conventions-api §8).
   - `openapi/_shared/components.yaml`: `Problem` (RFC 9457 + `code`, `errors`), respuestas `BadRequest`, `Unauthorized`, `Forbidden`, `NotFound`, `Conflict`, `UnprocessableEntity`, `PreconditionRequired`; esquemas `Page`, `CursorPage`, `Money`, `Quantity`, `I18nText`, `Decimal` (string con patrón `^-?\d+(\.\d{1,4})?$`), `UuidV7`; parámetros `IfMatch`, `Page`, `PageSize`, `Sort`, `Q`, `Limit`, `Cursor`.
   - `events/topics.yaml` (lista vacía, con el esquema del fichero documentado en comentario), `events/_README.md` con la convención de `conventions-events.md §5–§6`.
   - `permissions.yaml` vacío con su esquema: `code`, `resource`, `action`, `defaultRoles[]`, `step`.
   - `schemas/` para JSON Schema de payloads `jsonb` (p. ej. `delta_lines`).
7. **Scripts** (`tools/`):
   - `check-packages.sh`: falla si `Directory.Packages.props` contiene un paquete fuera de `tools/allowed-packages.txt` (generado desde `conventions-backend.md §10`) o alguno de MediatR, AutoMapper, FluentAssertions, MassTransit (ADR-0007).
   - `rule-coverage.sh STEP=<id>`: extrae los ids `[A-Z]{2,4}-R\d+` de la ficha del paso y busca cada uno en `src/**/*Tests*/**`, `web/**/*.spec.ts`, `solver/src/test/**`, `tests/e2e/**`; lista los que no aparecen y sale con 1 si hay alguno.
   - `check-permissions.sh`: cada `x-permission` de `contracts/openapi/*.yaml` existe en `permissions.yaml` (vacío ahora; útil desde 0.4).
8. **CI** (`.github/workflows/ci.yml`), jobs de `repo-structure.md §7`. En este paso funcionan de verdad `contracts` (Spectral + `check-permissions`), `dotnet` (build + test), `web` (lint + test + build) y `packages` (`check-packages.sh`). `db`, `conformance`, `jvm` y `e2e` existen con un paso `echo "pendiente: 0.3/0.5/4.4/1.3"`.
9. **`.github/pull_request_template.md`**: la plantilla de `delivery-process.md §3`.
10. `CLAUDE.md` y `docs/` en la raíz tal como están en la especificación (no se modifican en este paso).

**Aceptación I**
- [ ] `make build` y `make test` en verde en una máquina limpia (WSL2 o Linux) con .NET 10 SDK y Node LTS.
- [ ] CI en verde en un PR de prueba.
- [ ] Añadir `MediatR` a `Directory.Packages.props` hace fallar el job `packages` (demostrado en un commit de prueba revertido).
- [ ] Un OpenAPI de prueba sin `x-permission` hace fallar `contracts` (ídem).
- [ ] `make rule-coverage STEP=0.1` termina en 0 (la ficha no tiene reglas de negocio).

## Fuera de alcance

Docker compose (0.2), base de datos (0.3), cualquier endpoint o pantalla.

## Verificación de Luciano

1. `git clone` + `make build && make test` → todo verde, sin warnings.
2. Abrir un PR trivial → los jobs `contracts`, `dotnet`, `web`, `packages` pasan; `db`, `conformance`, `jvm`, `e2e` muestran "pendiente".
3. Revisar `Directory.Packages.props`: solo paquetes de la lista aprobada.
4. Revisar `contracts/openapi/_shared/components.yaml`: importes como string decimal, `Problem` con `code`.
