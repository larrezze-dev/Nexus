## Integración (Gate D)

1. Presupuesto v1 con 6 líneas → enviar → aprueba el jefe de proyecto (paso 1) → aprueba el controller (paso 2) → `APPROVED`.
2. v2 → aprobado → v1 `SUPERSEDED`.
3. Cambiar el `% reserva` de un concepto → las líneas de v1/v2 conservan el suyo (`reserve_pct_version_id`).
